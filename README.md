# transport-payment-manager

아버지의 운수 기록 정산을 위한 프로그램

## 주요 기능

- 월별 Excel 시트의 운수 기록 통합 조회
- 회사명 및 이름을 이용한 검색
- 미입금 및 입금 완료 기록 필터링
- 선택한 운수 기록의 입금 날짜 일괄 입력
- 원본 Excel 파일에 입금 날짜 반영

## 기술 스택

- Python
- PySide6
- openpyxl

## 데이터 구조

월별 시트 이름: `YYYY.MM`

| 열  | 항목      |
| --- | --------- |
| A   | 일        |
| B   | 회사명    |
| C   | 이름      |
| D   | 출발지    |
| E   | 목적지    |
| F   | 금액      |
| G   | 비고      |
| H   | 입금 날짜 |

실제 운수 기록 및 개인정보가 포함된 Excel 파일은 저장소에 포함되어 있지 않음.
